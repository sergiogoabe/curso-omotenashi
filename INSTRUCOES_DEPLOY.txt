================================================================================
TROUBLESHOOTING
================================================================================

PROBLEMA: Build falha no Vercel
───────────────────────────────
Solução:
  1. Verificar logs: https://vercel.com/dashboard → Deployments → Logs
  2. Confirmar todas as environment variables estão configuradas
  3. Testar localmente: npm run build
  4. Verificar DATABASE_URL está correto
  5. Executar manualmente: npx prisma db push

PROBLEMA: 502 Bad Gateway ao acessar a aplicação
──────────────────────────────────────────────
Solução:
  1. Verificar se DATABASE_URL está configurado
  2. Verificar conexão com Neon PostgreSQL
  3. Redeploy: Vercel Dashboard → Redeploy
  4. Aguardar 2-3 minutos

PROBLEMA: Auth loop infinito (redirect contínuo)
────────────────────────────────────────────────
Solução:
  1. Verificar NEXTAUTH_URL está correto (sem trailing slash)
  2. Verificar NEXTAUTH_SECRET foi gerado com openssl
  3. Confirmar NEXT_PUBLIC_APP_URL = NEXTAUTH_URL
  4. Limpar browser cache e cookies

PROBLEMA: 404 em rotas estáticas
─────────────────────────────────
Solução:
  1. Vercel Dashboard → Settings → Build & Deployment
  2. Limpar cache: Click "Redeploy" (não "Redeploy Latest")
  3. Executar: vercel cache rm
  4. Fazer novo push para forçar rebuild

PROBLEMA: Stripe webhooks não funcionando
──────────────────────────────────────────
Solução:
  1. Verificar STRIPE_WEBHOOK_SECRET está configurado
  2. Ir para Stripe Dashboard → Webhooks
  3. Configurar endpoint: https://curso-omotenashi.vercel.app/api/stripe/webhook
  4. Habilitar eventos: payment_intent.succeeded, payment_intent.payment_failed
  5. Testar com: stripe trigger payment_intent.succeeded
